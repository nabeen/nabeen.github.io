## COVID-19

これまで不思議と避けられていたのだけど、7 月末に感染し、丸 2 日ぶっ倒れていた。日曜起床後くらいから「あ、これちょっと熱出そう」という感覚になり、夜に発熱、翌朝も下がらなかったので slack で「今日無理ぽ」って連絡した足で病院へ。「コロナ増えてるんですよね〜」と言われて検査したら見事？に陽性。薬もらって帰宅して、そのまま寝て起きたら翌日みたいな感じだった。途中起きて薬飲んだりはしていたけど、ほとんど記憶がない。

翌日も熱はまだあったので仕事はお休みして安静に過ごした。で、ある程度回復したので次の日からは仕事した。リモートじゃなかったら丸 1 週間休まないといけなかったので、リモートは最高である。休みたくないわけではないが、休暇の残日数が少ないので。

その後しばらくは咳が出たり痰がからんだりしていたけど、今はもうそういうのも回復した。後遺症みたいなものはなかったな。不幸中の幸いである。

## タスクのバランス

先の見えない Enabling を含めたタスクと、明確にやるべきタスクを並行して進めていて、精神的なバランスがとれた状態を維持できている。先の見えないタスクだけだとストレスで発狂するし、やるべきタスクだけだと飽きがきてしまうので、この塩梅はちょうどいい。

あとは、思い立った改善をすぐに着手できる（タスク優先順位の意味合いで）ってのもかなり良い。

ついこの前やったケースを紹介すると、手元の開発環境構築に GitHub App のデバイスフローによる認証が組み込まれているのだけど、結構な頻度でブラウザを開いてコードを入力して...ということをやっていたので、GitHub CLI を使った認証方式を追加して、画面ポチポチする手間をなくした。GitHub CLI オンリーにしてしまうとツールのインストールを強制してしまうデメリットがあるので、これまでの処理はフォールバックとして残している。

## Claude Code vs Codex CLI

個人開発では Claude を結構使っているんだけど、Codex CLI がサブスク枠で使えるようになったので試した。GPT-5 の性能云々の前に、Codex CLI はまだツールとして未熟だなという印象で、Claude に慣れていると物足りなさを感じる。今後に期待。
