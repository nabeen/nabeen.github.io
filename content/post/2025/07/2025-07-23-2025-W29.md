## Agentic Coding

ここ最近は、プロダクト開発の足回りを整えるような仕事をしていて、そのうちの 1 つで Agentic Coding のあれこれをやっている。お試しで MCP サーバー書いたり、Coding Agent 用のドキュメントを整備したり。

MCP サーバーは、結果としてはベースの実装を整えただけで、社内展開はしていないのだけど、MCP サーバーの雰囲気は完全に理解したので、いざ何かを作るとき、サッと動き出せる状態にはなったと思う。ただこのあたりはあっという間に進歩するので、次やるときに今の知見が生きるとは限らないが。

ちなみに、MCP サーバーの実装にあたっては、やさしい MCP 入門 [^mcp] を最初に読んだ。日本語でざっくり雰囲気をつかめる良書だと思う。これを読んだあとに公式サイト [^official] を読むと、サクサク理解が進んだ。英語が得意な人は、直接公式サイトでも全然良いと思う。

めちゃくちゃ前に中古で買って、ずっと放置していたゲーデル、エッシャー、バッハ[^geb]。少し前まではプライベートでは Claude Code で遊んで Chrome 拡張作ったり、MCP サーバー作ったりしていたのだけど、最近ちょっとモチベが上がらない状況が続いていたので、モチベ向上のために読み始めた。
