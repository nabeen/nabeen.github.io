気がつけば今年ももう半分が過ぎてしまっている。このままだと今年も何も成さずに終わってしまうかもしれない。もっと命をすり減らしながら日々を生きていきたい。

## Agentic Coding

ここ最近は、プロダクト開発の足回りを整えるような仕事をしていて、そのうちの 1 つで Agentic Coding のあれこれをやっている。お試しで MCP サーバー書いたり、Coding Agent 用のドキュメントを整備したり。

MCP サーバーは、結果としてはベースの実装を整えただけで、社内展開はしていないのだけど、MCP サーバーの雰囲気は完全に理解したので、いざ何かを作るとき、サッと動き出せる状態にはなったと思う。ただこのあたりはあっという間に進歩するので、次やるときに今の知見が生きるとは限らないが。

ちなみに、MCP サーバーの実装にあたっては、やさしい MCP 入門 [^mcp] を最初に読んだ。日本語でざっくり雰囲気をつかめる良書だと思う。これを読んだあとに公式サイト [^official] を読むと、サクサク理解が進んだ。英語が得意な人は、直接公式サイトでも全然良いと思う。

## ゲーデル、エッシャー、バッハ

めちゃくちゃ前に中古で買って、ずっと放置していたゲーデル、エッシャー、バッハ [^geb]。少し前まではプライベートでは Claude Code で遊んで Chrome 拡張作ったり、MCP サーバー作ったりしていたのだけど、最近ちょっとモチベが上がらない状況が続いていたので、モチベ向上のために読み始めた...はずだった。

僕が持っているのは 20 周年記念版なのだけど、まえがきがなんと 40P もある。しかも何を言っているのかよくわからない。なぜ働いていると本が読めなくなるのか [^naze] という本があるが、そういうことなのだろうか...？

結局、全然頭に入ってこなかったので、そうそうに諦めた。また数年後に思い出したように引っ張り出してこようと思う。

## ダイエット、あるいは筋トレ

今週からまた真面目にダイエットを始めた。ピーク時から比べると、久しぶりにあった人には「痩せました？」って言われるくらいには落ちたっぽいのだけど、目標体重まではあと 6 キロくらいある。

散歩してからの ChocoZAP で、有酸素と筋トレをいい感じに混ぜている。そこまでシビアに組んでいるわけじゃないので、結構適当にトレーニングしている気もするが、やらないよりはマシ、と言い聞かせている。

## 放送大学の期末試験

可もなく不可もなくといった感じ。最近あんまり真面目にやってないので、単位落とさなければいいやくらいで考えている。下半期は、科目取るか取らないか、ちょっと悩むところ。そろそろ休んでもいいかもしれない。知的好奇心は、今は他でも満たせるので。

## No Man's Sky

さっきモチベが上がらないって書いたけど、その流れで久しぶりにゲームをやってみた。No Man's Sky[^sky] ってやつ。そこそこメジャーなタイトルなので、やったことある人もいるかもしれない。

まだチュートリアルっぽい感じはあるけど、楽しくやれている、が、これはかなり時間泥棒なゲームでもある。気づいたら深夜 3 時までやっていた。それくらいには楽しい。

ただやりすぎると生活に支障が出るので、もうちょっと短時間でサクッとやれるゲームに手を出すべきだったかもしれない。今、こういう終わりのないゲームをやるのは完全に悪手だったように思う。

## 参議院選挙

今週のビッグイベントはこれだったんじゃないか。当社比だと、過去一盛り上がっていたんじゃないかと思う。良くも悪くも。

僕の票はだいたいいつも死票になってしまうのだけど、それでもちゃんと投票はしている。もちろん今回も死票だった。比例は約に立ったかもしれない。

今回色々と政党を見ていく中で、やっぱり僕はチームみらいには興味があって、紆余曲折あって、PLURALITY[^plurality] にたどり着いた。読みたい本ではあったので、あぁここで繋がってくるんだ、という感じだった。これがコネクティングドットってやつなはず。

で、さらに調べてみると、原文が公開されている GitHub[^book] を見つけた。しかも音声ファイルもある。もちろん日本語ではないんだけど、原文をそのまま読んでもよし、NotebookLM に入れてもよし。僕はとりあえず散歩の時に Podcast 代わりに聞いてみようと思っている。英語わからんけど。

まぁそんなこんなの一週間だった。ちなみに 3 連休だったけど、朝起きれずにどこも行けなかった。無念。
